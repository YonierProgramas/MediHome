# MediHome

Sistema Java para gestionar servicios médicos domiciliarios.

El proyecto modela usuarios, pacientes, profesionales de salud, equipos médicos,
servicios domiciliarios, atención médica, mediciones de signos vitales y
notificaciones.

## Diagrama UML

El diagrama de clases se encuentra en la carpeta:

`diagramas/`

La carpeta está preparada para incluir `MediHome_Diagrama_Clases.png` y
`MediHome_Diagrama_Clases.vpp` cuando estén disponibles.

## Ejecución

Compila todos los archivos Java desde la carpeta del proyecto:

```text
javac *.java
```

Ejecuta la clase principal:

```text
java Main
```

El flujo de demostración está implementado en `Main.java`.
